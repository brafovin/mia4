# FRESHDROP – Marken-Shop (Demo)

Öffne `shop/index.html` im Browser (oder `python3 -m http.server -d shop`).

- Produkte: `shop/products.js` (Preise, Größen, Fotos über `img`)
- Funktionen: Marken-/Kategorie-Filter, Suche, Sortierung, Größenwahl, Warenkorb, Checkout, Lieferzeit 2–4 Werktage
- Noch offen für den Live-Betrieb: echte Zahlung (Stripe/PayPal), Backend/Bestellverwaltung, Impressum/AGB/Widerruf, echte Produktfotos
